# admin-rentals-app

Admin app for Thandra Cars (Expo / React Native). It talks to the Thandra API (`go-backend`).

## Run

```sh
npm install
cp .env.example .env     # set EXPO_PUBLIC_API_URL
npx expo start
```

## Scripts

- `npm run typecheck` checks the TypeScript.
- `npm run export:check` bundles the Android app to confirm it builds.
